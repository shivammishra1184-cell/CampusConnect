# CampusConnect – Interactive Campus Explorer

A responsive first-year web development project built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract `CampusConnect.zip`.
2. Open the `campus_explorer` folder in VS Code.
3. Open `index.html` in a browser. You can also use the VS Code Live Server extension.

## Features
- Responsive desktop and mobile layout
- Club cards and category filters
- Live search across clubs
- Event list with detail pop-ups
- Club detail pop-ups
- Registration form with HTML validation and a success message
- Mobile navigation menu

## Files
- `index.html` – page structure
- `style.css` – styling and responsive layout
- `script.js` – sample data and interactions

## Important
This is a front-end demo. Registration is not sent to a server or saved to a database. Club names, event dates, membership counts and locations are sample content; replace them with verified information from your own college before presenting.
